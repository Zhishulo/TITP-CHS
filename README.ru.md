# Китайский (упрощённый) патч для This Is the President

Для Steam-версии **This Is the President** (Unity 2019.4.5f1 / Mono / Steam AppID **730430**).
**Полная локализация**: все 72 группы событий, основной словарь, документы, газеты, твиты, обучение и
интерфейс (28 144 записи / ~1,07 млн знаков).

Патч состоит из двух частей:

| Часть | Что делает | Меняет файлы игры? |
|------|------------|--------------------|
| **Внедрение перевода** (скрипт Python, однократно) | Записывает китайский текст во все языковые слоты `resources.assets` / `sharedassets0.assets` (замер этой сборки: **34 081 строка в 1 407 TextAsset**) и подменяет встроенные данные 15 legacy-шрифтов `Font` на подмножество Noto Sans SC | Да (оригиналы копируются в резервную папку при первом запуске) |
| **Плагин BepInEx `TITPFontFix` v7** | ① Во время работы подключает динамический CJK-атлас к статическим TMP-шрифтам, которые используют 932 компонента `TMP_Text` (в шрифтах игры нет китайских глифов — без плагина будут □□□); ② переопределяет «зашитые» в префабах/сборке строки интерфейса через `ui_extra.tsv` (158 записей), включая русские и немецкие остатки в официальной английской версии | Нет (только BepInEx) |

> Половины недостаточно: **только перевод = одни квадраты; только плагин = всё по-прежнему по-английски.**

## 1. Требования

- Windows 10/11 x64
- Лицензионная копия игры в Steam
- **Python не нужен**: в архиве есть портативная среда (`runtime\python\`, Python 3.13 + UnityPy, ~57 МБ).
  Если вы удалили `runtime\`, подойдёт свой Python 3.9+ (64-бит, с галочкой *Add python.exe to PATH*).
- Не менее 500 МБ свободного места (для резервной копии оригинальных assets)

## 2. Установка (рекомендуется: скрипт в один клик)

1. Распакуйте папку `TITP-CHS` целиком в любое место (например, `D:\TITP-CHS`).
   > Лучше **без китайских символов и пробелов** в пути — на некоторых системах командная строка их не переваривает.
2. Запустите **`install.bat`** двойным щелчком.
   - Скрипт использует портативный Python из архива; к системному он обращается только если первого нет.
   - Папка игры определяется автоматически; если не нашлась — перетащите её в окно консоли.
   - Перед внедрением оригинальные `resources.assets` / `sharedassets0.assets` копируются в `assets_backup\`.
3. Увидев `安装完成` («установка завершена»), запускайте игру из Steam как обычно.

Первый запуск на несколько секунд дольше обычного (плагин запекает CJK-атлас шрифта), дальше — как всегда.

## 3. Установка (вручную)

```bat
:: 1) внедрить перевод (папка игры определяется автоматически)
runtime\python\python.exe patch.py

:: либо указать папку игры вручную
runtime\python\python.exe patch.py --game "C:\Program Files (x86)\Steam\steamapps\common\This Is the President"

:: 2) установить BepInEx и плагин
::    скопировать winhttp.dll, doorstop_config.ini и папку BepInEx\ из bepinex\ в корень игры
::    скопировать plugins\TITPFontFix.dll в <игра>\BepInEx\plugins\
::    скопировать data\fonts\sub-Regular.ttf и data\ui_extra.tsv в <игра>\BepInEx\plugins\TITP-CHS\
```

После запуска в корне игры появится `BepInEx\LogOutput.log`; строки
`TITP font fix v7: ... uiMap=158` и `baked 'TITP-CJK' from legacy Font 'LiberationSans'` означают, что плагин работает.

## 4. Структура архива

```
TITP-CHS\
├─ install.bat                  установка в один клик
├─ uninstall.bat                вернуть оригинальные assets / удалить плагин
├─ patch.py                     инжектор перевода (Python + UnityPy, самодостаточный)
├─ requirements.txt
├─ runtime\python\              портативный Python 3.13 + UnityPy (можно удалить)
├─ data\
│  ├─ zh\*.json                 данные перевода (en→zh, 75 файлов, 28 144 записи)
│  ├─ ui_extra.tsv              таблица переопределения «зашитых» строк UI (158 записей)
│  └─ fonts\sub-Regular.ttf     подмножество Noto Sans SC (SIL OFL 1.1)
│     fonts\OFL.txt             лицензия шрифта (обязательна к распространению)
├─ bepinex\                     BepInEx 5.4.22 x64 (LGPL-2.1, из официального релиза)
├─ plugins\TITPFontFix.dll      плагин шрифта/интерфейса (собственная разработка, MIT)
└─ docs\
   ├─ OFFICIAL_SUBMISSION.md    материалы для разработчика
   ├─ TERMINOLOGY.md            глоссарий и правила перевода
   └─ LETTER_TO_DEVELOPER.md    письмо команде разработчиков (кит. / англ. / рус.)
```

## 5. Удаление / откат

```bat
uninstall.bat
```

Скрипт:
1. вернёт оригинальные файлы из `assets_backup\` поверх `resources.assets` / `sharedassets0.assets`;
2. удалит `<игра>\BepInEx\plugins\TITPFontFix.dll` и папку данных `TITP-CHS\`;
3. оставит сам `BepInEx\` (если он не нужен — удалите вручную `winhttp.dll`, `doorstop_config.ini` и папку `BepInEx\`).

Проверка целостности файлов в Steam тоже восстанавливает assets, но **не** удаляет BepInEx.

## 6. Частые вопросы

**Q: Везде квадраты □□□.**
Плагин не загрузился. Проверьте: ① лежит ли `winhttp.dll` в корне игры; ② есть ли `BepInEx\plugins\TITPFontFix.dll`;
③ нет ли ошибок в `BepInEx\LogOutput.log`.

**Q: Всё ещё по-английски.**
Внедрение не сработало. Запустите `patch.py` заново и убедитесь, что в конце выведено `translated N strings`, где N > 0
(нормальное значение — около 34 000).

**Q: После обновления игры локализация пропала.**
Обновление Steam перезаписывает assets — просто запустите `patch.py` ещё раз (резервная копия не перезаписывается).

**Q: Не забанят ли меня, работают ли достижения?**
BepInEx — обычный фреймворк для модов Unity, античита в игре нет, достижения разблокируются как обычно.
Сетевая часть не затрагивается.

**Q: Кое-где интерфейс всё ещё на английском.**
Такие остатки редки. Плагин раз в 30 кадров сканирует текст интерфейса и переопределяет его из `ui_extra.tsv`.
Если что-то нашлось — добавьте строку `английский<TAB>китайский` в `<игра>\BepInEx\plugins\TITP-CHS\ui_extra.tsv`
(строки, начинающиеся с `#`, — комментарии; значение `<clear>` очищает текст).

## 7. Известные особенности

- Несколько чисто графических элементов (иконки, метки на карте) перевести невозможно.
- Вторая и третья строки панели представления персонажа очищаются или допереводятся плагином (записи `<clear>`
  в `ui_extra.tsv`) — так и задумано.
- Русские/немецкие строки, оставшиеся в официальной английской версии (панель «охота на крота», название
  должности главы аппарата и др.), переведены на китайский вместе со всем остальным.
- Некоторые подписи интерфейса переносятся на вторую строку — это нормально.
